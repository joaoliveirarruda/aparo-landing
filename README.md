# Aparo

Landing page do Aparo, um assistente pessoal no WhatsApp.

Feita com React, Vite e Tailwind CSS. A conversa interativa usa dados ilustrativos e não executa ações reais.

## Desenvolvimento

Requer Node.js 22 e npm.

```sh
npm ci
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

O build é gerado em `dist/`.
